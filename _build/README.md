# How to edit the site

The site is static HTML generated by `build.py`. After any change, run:

    python3 _build/build.py

Then commit and push. Needs Python 3 with Pillow (`pip3 install pillow`).

## What to edit

| What | Where |
|---|---|
| Amazon Associates tag (earns commission on all search links) | `config.json`, field `amazon_tag` (for example `yourname-20`) |
| Public site address (for sharing previews and the pin-links list) | `config.json`, field `site_url` |
| Short intro text and photo on the About page | `config.json`, fields `about_intro`, `about_photo` |
| An exact affiliate link for one product | `affiliate_links.json`, key `outfit-slug/N` (N = product number, starting at 1) |
| Product photo, price, "price checked" date, budget limit | `product_data.json`, same keys. Fields: `price`, `checked`, `image`, `url`, `cap` |
| Outfits, tips, products | `outfits.py` |
| Seasons, quiz, capsule builder, checklist | `extras.py` |

## Notes

- Without a tag, shop buttons are plain Amazon searches. Add the tag to start earning.
- "Budget finds" and "Premium picks" add an Amazon price filter to the search.
- The newsletter form works on Netlify (Forms, enable form detection). On other hosts it will not collect emails.
- The list of pin destination links is written to `corporate-closet-pin-links.md` one folder above the project.
